This is a personal project.
The my_mpu6500_project.c contains the logic for a basic driver intended to enable core functionality of the mpu6500 accelerometer.
In the main.c i have added a small example on how to read a data from the sensor.
The driver is intended to work with an ESP32
I have based my work on accessing registers and consulting the data sheet/ register map from InvenSense.
Im currently still working on developing more functionalities like temp readings and more effective transactions on the I2C bus.
